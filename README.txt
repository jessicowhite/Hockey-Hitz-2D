NHL Hitz 2002 (remake) - Windows

RUN
  Double-click "NHL Hitz 2002.exe". Keep it in this folder: it needs the other files here.
  You can put this folder anywhere (Desktop, C:\Games, ...). To make a shortcut, right-click the
  .exe > Send to > Desktop (create shortcut). F11 toggles fullscreen.

GPU
  The app asks Windows for the high-performance (dedicated) GPU and does not fall back to
  software rendering. On a laptop with two GPUs you can also set it in
  Settings > System > Display > Graphics > Browse > "NHL Hitz 2002.exe" > Options > High performance.
  After the first launch, %APPDATA%\NHL Hitz 2002\gpu-status.txt shows what it is running on
  (webgl / webgl2 should say "enabled"). In game, F3 shows the frame-rate overlay with the GPU name.

CONTROLS
  Xbox controller: A pass, X shoot (hold = slapshot), Y poke / hold check / one-timer pass,
  B juke / dive, RT turbo, Menu pause.
  Rebind anything: C or View on the title screen, or Controls in the pause menu.
